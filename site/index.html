What it does

        

          Claude Code does the work. Hopper keeps track of it, and gets you back into the
          conversation that needs you.
        

        

          

            
? One list of everything

            

              Every conversation that isn't done, from every project and every login, grouped into
              waiting on you, drafts, running and up next. n jumps to the next one that
              needs you.
            

          

          

            
⏎ The real session, in place

            

              A conversation opens in the right-hand panel as the actual Claude session, every key
              going to Claude. ctrl+] comes back to the list and leaves it running.
            

          

          

            
bh Several logins, routed

            

              Add each Claude login once and say which projects it runs. Work goes to the first one
              that's signed in and has room, and each shows its usage against the week.
            

          

          

            
☾ Routines and overnight

            

              Prompts that run on a schedule, and drafts queued for tonight. They work on a branch,
              never push to main, and leave a report for the morning.
            

          

        

      


      

        
Install

        
Mac only for now. You need:

        
    
          
  • Node 22.6 or later
    • 
          
  • pnpm
    • 
          
  • Claude Code, signed in
    • 
        

        

          
          
git clone https://github.com/saltbark/hopper.git
cd hopper
pnpm install && pnpm build
pnpm link --global

        

        

          
hopper init     # config, home folder, and your Claude login
hopper          # the app

        

        
A one-line installer and versioned releases are on the way.
