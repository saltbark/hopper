Toss work in the hopper.

Hand work to Claude Code and keep track of it. One window shows every conversation across your projects and your Claude logins, which ones are waiting on you, and opens them right there.

install macOSnode ≥ 22.6claude code 
curl -fsSL https://hopper.saltbark.com/install.sh | sh
hopper init # config, home folder, your Claude login
hopper

Installs to ~/.hopper/app and links ~/.local/bin/hopper. Run it again to upgrade.

hopperclick to drive it

01 what it does

        

          Claude Code does the work. Hopper keeps track of it, and gets you back into the
          conversation that needs you.
        

        

          

            
? One list of everything

            

              Every conversation that isn't done, from every project and every login, grouped into
              waiting on you, drafts, running and up next. n jumps to the next one that
              needs you.
            

          

          

            
→ The real session, in place

            

              → opens a conversation in the right-hand panel as the actual Claude
              session, every key going to Claude. ← at Claude's empty prompt, or
              ctrl+] from anywhere, comes back to the list and leaves it running.
            

          

          

            
bh Several logins, routed

            

              Add each Claude login once and say which projects it runs. Work goes to the first one
              that's signed in and has room, and each shows its usage against the week.
            

          

          

            
☾ Routines and overnight

            

              Prompts that run on a schedule, and drafts queued for tonight. They work on a branch,
              never push to main, and leave a report for the morning.

To build it yourself instead, you also need pnpm.

$ cd hopper
$ pnpm install && pnpm build
$ pnpm link --global
